# UI

FINSTRAT2 pouziva vizualni jazyk legacy aplikace. Zaklad tvori tmave plochy
`#0c0c0e`, `#0f0f12`, `#111114` a `#161619`, hranice `#1e1e24`, primarni text
`#e4e4e7` a Bitcoin akcent `#f7931a`. Uspech je zeleny `#22c55e`, dluhy a
destruktivni akce cervene `#f43f5e`.

Desktop ma sidebar siroky 216 px a header vysoky 52 px. Stranky pouzivaji ploche
metricke pasy a souvisle radky oddelene jednobodovou hranici. Dialogy maji tmavy
panel, polomer 12 px a stejny system formularovych prvku. Na sirce do 768 px se
sidebar nahrazuje spodní navigaci vysokou 58 px a panelem `Vice`.

Nove funkce, ktere legacy aplikace nemela, zachovavaji stejne tokeny a semanticke
barvy. Funkcni chovani, vlastnictvi dat a API nejsou vizualni migraci zmenene.
